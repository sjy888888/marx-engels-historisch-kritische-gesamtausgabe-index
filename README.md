# 马克思恩格斯历史考证版 卷目索引

**Marx-Engels-Gesamtausgabe（MEGA）卷目索引、抓取工具，以及 54 卷 OCR 全文语料。**

查「某篇著作在马克思恩格斯历史考证版哪一卷、第几页」。

## 这个仓有什么

三部分，分量完全不同，先说清楚：

| 部分 | 内容 | 位置 |
|---|---|---|
| **① 卷目索引工具** | 抓取、转文本、建索引、核验的 21 个脚本 | 仓库根目录 |
| **② 卷目索引数据** | 各卷收录了什么、起止页、篇幅 | 由脚本生成 |
| **③ 54 卷 OCR 全文** | 德意志意识形态、1844 手稿、大纲、资本论四个版本、书信、摘录 | `corpus/` |

## ★ 先说语料的性质与边界

`corpus/` 里 54 个 txt 是**从 PDF 抽取/OCR 的德文原文**，不是官方排版件，也不是中文译本。

### 每一卷头部都带这几行

```
页码体例：【pN】= 从该页页眉/页脚实测到的印刷页码
         【p?|pdfN】= 该页无印刷页码，只记 PDF 页序
页码实测率：628/651 = 96.5%
众数偏移（PDF页-印刷页）= 9
引用规则：只有【pN】的页码可直接引；【p?】的段落引用写「页码待核」
```

**这是本仓最有价值的东西，也是最容易出事的地方。**

页码实测率不是 100%。以《资本论》第一卷 1867 初版为例：651 页里 628 页读到了印刷页码，23 页没有。这 23 页必须写「页码待核」，不能拿 PDF 页序冒充。

### 逐卷页码实测率

每卷头部都写了。低到 78.9%（1844 年手稿卷 400/507），高到 96.5%（资本论 1867 初版 628/651）。

**引用前请先看那一行的数字。** 低于 90% 的卷，段落级引用要格外小心。

### 配套 pages.json

每个 txt 配一个 `*.txt.pages.json`，记录逐页结构化信息：

```json
{ "pdf_page": 2, "printed": null, "zone": null, "chars": 326, "first": "KARL MARX" }
```

`printed` 是实测到的印刷页码，`null` 表示这页没读到。写程序做页码校验时用这个，比读 txt 里的标记可靠。

## 关键判断：索引不给页码，语料给实测页码

这是两件事，别混：

**索引**（`mega_index.py`）回答「去哪一卷找什么」，不给页码。原话：

> 这批文件没有印刷页码（前置部分用罗马数字），文件头自己写明了「标的是 PDF 页序，不是印刷页码」。所以索引要做的是：让你知道去哪一卷找什么，不是给页码。

**语料**（`corpus/`）给的是**逐页实测页码**，每卷头部写明实测率。读到就标，读不到就标 `p?`，绝不猜。

## 用法

```bash
# 抓某一卷的目录与导论
node mega-fetch.mjs I/5

# 建全量索引
python build_mega_index.py
python mega_index.py

# 查某篇在哪
node mega-find.mjs "德意志意识形态"
node mega-find.mjs "政治经济学批判大纲"

# 核验手上的 PDF 是不是真的
python verify_mega.py
python verify_volumes.py
```

## 精度声明

三条，缺一条都不行：

1. **页码是实测的，不是算的。** 每卷头部的实测率就是证据。低实测率的卷，别拿页码去引。
2. **德文原文，未译。** 中文引用须自行翻译，并标注「据德文原文译」。
3. **OCR 有错字。** 错字审计方法见姊妹仓 [`chinese-ocr-audit`](https://github.com/sjy888888/chinese-ocr-audit)。
